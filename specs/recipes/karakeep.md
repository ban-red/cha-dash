---
title: An API key, which has full access
summary: Karakeep's API keys act as the user who made them, with everything that user can do to their bookmarks. There is no read-only key. The key decides whose bookmarks are counted.
access: full
discover:
  - {scheme: http, port: 3000, path: /, match: Karakeep}
---

## Create the key

Signed in as the user whose bookmarks you want counted, open **Settings → API Keys**, create one named Cha Dash, and paste it into **API key**. Karakeep shows it once.

## Notes

- Delete the key on the same page to cut Cha Dash off; it then asks to reconnect.
