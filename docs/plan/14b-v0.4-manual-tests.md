# 14b · v0.4: manual tests

> **Status: open.** The checks for [14 · v0.4](14-v0.4.md) that need the lab, a person, a device or a build. Automated tests cover the code; this is what they can't. Run before `0.4.0` is tagged. Each run against the lab needs the maintainer's go-ahead with its targets named.

**House rule:** reading the lab needs a go-ahead. **Writing to the lab needs a go-ahead per run against named targets**, snapshots, backups and updates included. Builds, dev servers and Docker need the maintainer's say.

**Which hub.** `bun run dev:real` sees the real lab but has no node, so it has no container updates. Rollouts run on the sandbox hub (CT 3696 on Mars, `192.168.11.88:3696`), which pvedocker's node reports to. It runs a local build: `docker buildx build --platform linux/amd64 -t chadash-local:<name> --load .`, then `docker save | ssh root@192.168.11.88 docker load` and the image in `/root/chadash/compose.override.yaml`. Back up its `chadash_data` volume first.
