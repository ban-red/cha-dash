# ADR-0005 · v0.1 scope: the Front Page

**Status:** accepted · **Date:** 2026-10-03 · **Roadmap:** [decision 5](../plan/04-roadmap.md#decisions), [v0.1](../plan/04-roadmap.md#v01-front-page-read-only-beautiful-live)

## Context

"The front page of your home" could mean a lot: infrastructure, smart home, family boards, feeds. v0.1 has to be small enough to finish and good enough to replace the dashboard the maintainer runs today ([ADR-0004](0004-dogfood-the-maintainers-homelab.md)).

## Decision

**v0.1 is read-only, beautiful and live: infrastructure first, plus the home integrations the maintainer actually uses** (Home Assistant, Frigate, the media calendar, clock and weather).

**In v0.1:**
- Install with `docker compose up -d`. First run: setup token → owner account → passkey. *Replaced by [ADR-0028](0028-first-run-without-a-setup-token.md): there's no setup token any more.*
- Boards and sections, edit in place, layout history and undo. Light, dark and OLED themes.
- The status sentence, a Needs attention section, the Inbox (discoveries and repairs), and ⌘K search.
- An installable PWA that shows last-known state when offline.
- Docker reads through a read-only socket proxy.
- Tier 0 integrations: Proxmox VE (many instances and clusters), PBS, Unraid, Docker, Traefik, OPNsense, Uptime Kuma, Home Assistant, Frigate, Plex, Sonarr, Radarr, Prowlarr, qBittorrent, Immich, built-in checks.
- Internal specs: Tautulli, Bazarr, Mealie, Linkding, Karakeep. Breadth: Jellyfin, Pi-hole, AdGuard, SABnzbd.
- YAML export and import with a diff preview, the **Homepage importer** (the first of several importers, each named after its source; Homarr and plain YAML follow in v0.2), and least-privilege token recipes.

**Not in v0.1:** actions, audit and roles, the local node and owned stacks (v0.2); the Family board and notifications (v0.2); history, the Atlas and cause hints (v0.3); updates and backups (v0.4); feeds, wall and TV modes, public specs (v1.0).

**Done when:**
- the maintainer switches off their Homepage;
- a fresh install goes from `docker compose up -d` to a populated, live page in **under 3 minutes**, with no YAML written;
- performance budgets are met and WCAG AA checks pass;
- 10 external beta users run it every day.

## Consequences

- No write access to anything in v0.1. Control arrives together with the audit log, roles and the safety ladder.
- Discovery and the importer carry first-run value, so they're core v0.1 work, not polish.
- The declarative spec engine is proven internally on five simple apps before its format goes public.
- Breadth integrations make v0.1 useful beyond one lab.

## Alternatives considered

- **Control in v0.1.** Useful sooner, but it would ship write access before audit, roles and step-up auth exist.
- **Infrastructure only.** Smaller, but it misses the "home" that makes the page worth opening every day.
- **Home-first, with the Family board and feeds.** Broader appeal, but it delays replacing the maintainer's dashboard.
